## Trust Boundaries

| Boundary         | Description                                                                                                                                     |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| file read -> AJV | marketplace.json is read from filesystem and validated against schema. Untrusted if modified outside validation flow.                           |
| schema download  | Schema fetched from json.schemastore.org. If MITM'd, could accept invalid marketplace files. Mitigated by storing local copy in tests/schemas/. |
