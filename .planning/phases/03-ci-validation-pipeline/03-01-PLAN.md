</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author -> CI workflow | Untrusted input (marketplace.json changes) crosses into CI |
| CI workflow -> GitHub API | Authenticated API calls using GITHUB_TOKEN |
| CI workflow -> opencode.ai proxy | Authenticated API calls using OPENCODE_API_KEY secret |
| CI workflow -> plugin source repos | Untrusted external repos checked via git ls-remote |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | settings.json with API key in CI | mitigate | GitHub Actions auto-masks ${{ secrets.* }} in log output; heredoc uses single-quoted delimiter to prevent shell expansion |
| T-03-02 | Tampering | Malformed marketplace.json in PR | mitigate | AJV schema validation (Vitest) + `claude plugin validate --strict` provides two-layer defense |
| T-03-03 | Tampering | @anthropic-ai/claude-code npm package | mitigate | Package published by official Anthropic npm account; ASSUMED per Package Legitimacy Audit (slopcheck unavailable) |
| T-03-04 | Denial of Service | GitHub API rate limiting during source verification | mitigate | Use GITHUB_TOKEN for 1000 req/hr vs 60 unauthenticated (per D-11) |
| T-03-05 | Tampering | Malicious plugin source URL | accept | Source verification only checks reachability, not code content. Curated single-author marketplace limits exposure. |
| T-03-SC | Tampering | npm installs (claude-code) | mitigate | blocking-human checkpoint in Plan 02 will verify package legitimacy on first CI run |
</threat_model>
